# rls-auto

## Tools in this repo

- **`shorts-image-tool/`** – Python command-line tool that sources images for
  YouTube Shorts from TMDB, Google Images (SerpAPI), Unsplash, Pexels and
  Pixabay, and crops them to 1080x960. See
  [shorts-image-tool/README.md](shorts-image-tool/README.md) for setup.
